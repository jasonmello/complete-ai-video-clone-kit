# Decisions

English first; pt-BR below each entry.

**2026-11-22 · A skill, not an MCP server.** Every tool is already a CLI or Python library Claude can call. What was missing was the order and the file contract between them, which is what a skill provides. An MCP server would add a layer without adding capability.
*pt-BR: Skill, não MCP. As ferramentas já são CLIs ou bibliotecas; faltava a ordem e o contrato de arquivos, que é o que uma skill dá.*

**2026-11-22 · Name: "Complete AI Video Clone Kit".** Chosen by the author over "Reel Blueprint" and "AI Video Remake Kit". Known trade-off: "clone" can read as copying content. So the README opens by defining it as cloning the editing structure only.
*pt-BR: Nome escolhido pelo autor. Risco conhecido: "clone" pode soar como cópia de conteúdo, por isso o README abre definindo que clona só a estrutura de edição.*

**2026-11-22 · Compliance guardrails.** Flow is generated by hand (no browser automation of Google services), the reference can be the user's own file instead of a download, and no specific voice-cloning product is named. The skill reminds the user about AI labels and music licensing before publishing. The goal is that nothing in the repo invites a terms-of-service violation or a policy report.
*pt-BR: Flow só à mão, referência pode ser arquivo próprio, nenhum produto de voz citado, e lembrete de rótulo de IA e licença de música antes de publicar.*

**2026-11-22 · License Apache-2.0.** The author's default for skills: free adoption, a patent grant, and a NOTICE that forks must keep.
*pt-BR: Apache-2.0, o padrão do autor para skills.*

**2026-11-22 · uv + PEP 723 inline dependencies.** No sudo, no Homebrew, no system Python. macOS ships Python 3.9, which is too old for these libraries.
*pt-BR: uv com dependências declaradas no próprio script; nada de sudo, Homebrew ou Python do sistema (3.9, velho demais).*

**2026-11-22 · FFmpeg from imageio-ffmpeg as a fallback.** It gives a working binary with libx264 on macOS and Linux without a package manager. `setup.sh` copies it to `~/.local/bin` because yt-dlp needs `ffmpeg` on PATH to merge streams.
*pt-BR: FFmpeg do imageio-ffmpeg como alternativa; o setup copia para `~/.local/bin` porque o yt-dlp precisa dele no PATH.*

**2026-11-22 · yt-dlp on Python 3.12, Node as JS runtime.** On Python 3.9, uv resolved a 2025 release that YouTube rejects. Since late 2025, YouTube extraction needs a JS runtime, and yt-dlp only enables deno by default.
*pt-BR: yt-dlp no Python 3.12 (no 3.9 ficava numa versão de 2025) e Node como runtime de JavaScript.*

**2026-11-22 · Whisper gets decoded audio.** faster-whisper's own decoder breaks with recent PyAV (`metadata_errors` argument). `analyze.py` decodes with librosa and passes the array instead of pinning PyAV.
*pt-BR: o analyze.py decodifica o áudio com o librosa e entrega o array ao Whisper, em vez de fixar a versão do PyAV.*

**2026-11-22 · Demucs with torch/torchaudio < 2.9.** torchaudio 2.9+ needs torchcodec to save audio, and Demucs 4.0.1 fails without it.
*pt-BR: Demucs com torch/torchaudio abaixo de 2.9, que passou a exigir torchcodec.*
